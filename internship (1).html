The internship journey

Eight tasks. Thirty days. One working platform.

The TechBridge Web Development internship is a structured 30-day build, not a stack of lessons. You complete eight practical tasks in sequence, each one adding a working piece to the same project, so your skills — and the platform you're building — grow together from a single HTML page to a complete site.

The build, task by task

Each module below is one task in the internship. Open a task to see what you're expected to build.

Day 1 Task 1

Build the TechBridge Homepage

Create the first version of the TechBridge website using HTML and CSS — the page you're on now started here.

Beginner
What you'll build
  • A structured homepage with a hero, about section, and contact details
  • A layout built entirely in semantic HTML5
  • A first CSS pass covering type, color, and spacing
Day 4 Task 2

Build the TechBridge Programs Experience

Create a Programs experience that presents TechBridge's available learning programs in depth.

Beginner
What you'll build
  • A dedicated Programs page linked from the homepage
  • Detailed presentation of each track and the skills it teaches
  • Consistent navigation between Home and Programs
Day 8 Task 3

Build the Internship Tasks Experience

Create an interface — this page — that presents the internship tasks and helps visitors understand the journey.

Beginner → Intermediate
What you'll build
  • A page representing all 8 tasks with day, title, and description
  • A visual structure that communicates sequence and progression
  • Navigation connecting Home, Programs, and Internship Tasks
Day 11 Task 4

Build an Interactive Task Tracker

Use JavaScript to make the internship task experience interactive, so progress can be tracked as tasks are completed.

Intermediate
What you'll build
  • Task state (done / in progress / upcoming) saved as you go
  • JavaScript-driven interactions layered on the Task 3 page
  • A page that still works with JavaScript disabled
Day 15 Task 5

Build the Intern Registration Experience

Create a professional registration and onboarding interface for new TechBridge interns.

Intermediate
What you'll build
  • A registration form with validation and clear input states
  • An onboarding flow that feels consistent with the rest of the site
  • Accessible, well-labelled form fields
Day 19 Task 6

Build the Task Submission System

Create an interface through which interns can prepare and submit their completed task work.

Intermediate
What you'll build
  • A submission form for links, files, or write-ups per task
  • Clear confirmation and status feedback after submitting
  • A structure that can connect to a real backend later
Day 22 Task 7

Build the Intern Dashboard

Create a dashboard where an intern can view their profile, progress, tasks, and submissions in one place.

Intermediate → Advanced
What you'll build
  • A single view combining profile, progress, and task history
  • Reusable components pulled from earlier tasks
  • A layout that scales from a handful of tasks to many
Day 26 Task 8

Build the Complete TechBridge Internship Platform

Combine every component built during the internship into one complete, working TechBridge platform.

Advanced
What you'll build
  • Homepage, Programs, Tasks, Registration, Submission, and Dashboard, unified
  • One consistent design system across every page
  • A finished platform ready to demo end to end
